# Публикация Ma-Ru

Claude Code и Codex читают свои каталоги из ветки `main` этого репозитория. Оба указывают на один каталог `plugins/ma-ru`. Claude Code получает версию из `.claude-plugin/plugin.json` плагина. Для Codex та же версия записана в `.codex-plugin/plugin.json`. После обновления каталога пользователю может понадобиться обновить локальный плагин и открыть новый чат. [Руководство Claude Code](https://code.claude.com/docs/ru/plugins/create-marketplace) · [Установка в Codex](../README.md#быстрый-старт-на-windows-macos-и-linux)

## Как выпустить версию

1. Поменяйте версию в `pyproject.toml` и выполните `python scripts/marketplace_versions.py --sync`. Команда обновляет манифесты, пакет n8n и команды скачивания. Запуск без флага проверяет согласованность.
2. Запустите тесты, влейте изменения в `main` и отправьте тег `vX.Y.Z` на этот коммит. GitHub Actions проверит Windows, macOS и Linux и опубликует архивы с контрольными суммами.
3. После публикации GitHub Release автоматически запускаются отдельные задания ClawHub для плагина и для навыка. Они проверяют публичную версию и содержимое. Для площадок с ручной модерацией GitHub создаёт задачу с номером версии, ссылкой на релиз и состоянием записи в PickAPlugin. Если задание реестра упало, исправьте причину и выберите **Re-run failed jobs** у запуска тега. Уже опубликованные файлы с совпадающим хешем принимаются повторно.

## OpenClaw и ClawHub

Для первой публикации и последующих релизов сохраните токен издателя ClawHub с правом публикации от имени `grebennikovxyz` в секрете GitHub Actions `CLAWHUB_TOKEN`. Его использует только задание релиза. Отдельный навык публикуется из `plugins/ma-ru/skills/ma-ru`, полный плагин — из проверенного архива GitHub Release. Страница публикации может появиться после проверок реестра. Для установки из GitHub уже доступна команда `openclaw plugins install ma-ru --marketplace grebennikovxyz/ma-ru-plugin`.

Включение обеих публикаций токеном даёт ClawHub право распространять текст отдельного навыка по MIT-0. Эта лицензия разрешает использование, изменение и распространение без указания автора. Полный пакет Ma-Ru поставляется по Apache-2.0. [Лицензия навыков в ClawHub CLI](https://unpkg.com/clawhub@0.27.0/dist/schema/license.js)

После приёма в ClawHub идентификатор полного плагина — `@grebennikovxyz/ma-ru`, идентификатор навыка — `ma-ru` издателя `grebennikovxyz`. Отдельный навык пригодится тем, у кого сервер Ma-Ru уже подключён на Gateway. [Создание навыков](https://docs.openclaw.ai/tools/creating-skills) · [Публикация в ClawHub](https://docs.openclaw.ai/clawhub/publishing)

## PickAPlugin и публичный каталог OpenAI

PickAPlugin принимает ссылку на репозиторий и описание письмом. Первоначальная заявка отправлена 26 ноября 2026 г. Каталог ежедневно перечитывает публичные источники. Бейдж можно добавить после появления записи. [Правила подачи](https://pickaplugin.com/submit) · [Руководство по распространению](https://pickaplugin.com/guides/publish-codex-plugin)

Личный плагин ChatGPT обновляется через Plugin Creator. Для публичного OpenAI Plugins Directory действует отдельный порядок. Ma-Ru использует локальный stdio MCP. По правилам OpenAI организация должна получить допуск к desktop-only submissions и пройти проверку издателя. Для подачи подготовьте автономный пакет, тестовый ящик Mail.ru для проверяющего, публичные ссылки на политику конфиденциальности, условия и поддержку, ссылку на запись демонстрации и заметки к версии. Данные тестового ящика вводятся отдельно в портале. Когда меняются инструкции навыка или метаданные, загружается новый ZIP. [Локальные плагины](https://developers.openai.com/plugins/deploy/desktop-only) · [Портал публикации](https://platform.openai.com/plugins)

### Сценарии для проверки на тестовом ящике

| Поручение | Ожидаемый результат |
| --- | --- |
| Показать подключённые ящики | Видны адрес и права тестового ящика. |
| Найти непрочитанное письмо с заранее известной темой | Результат содержит нужные папку, тему и ссылку на письмо. |
| Прочитать найденное письмо | Содержимое соответствует тестовому письму, признак непрочитанности сохраняется. |
| Подготовить ответ | В Черновиках появляется письмо с верными отправителем, адресатом и темой. |
| Отменить отправку в течение 30 секунд | В очереди операция переходит в остановленное состояние. |
| Попытаться отправить из ящика с правом только на чтение | Плагин сообщает о недостаточных правах. |
| Открыть ссылку на письмо из закрытой папки | Правило папки блокирует доступ. |
| Отклонить подтверждение переноса двух писем в Корзину | Оба письма остаются в исходной папке. |
